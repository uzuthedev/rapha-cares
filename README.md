# Rapha Cares

A polished, frontend-only single-page app for a Christian mental health resource platform.

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Stack

- React 18 + Vite
- Tailwind CSS
- All UI lives in `src/App.jsx` (modular components, inline Tailwind)

## Features

- Welcome modal on first load
- Tabbed navigation (Therapy, Psychiatrists, Other Support, Resources)
- Mock provider cards, prayer form, resource grid
- Fixed 988 safety banner
